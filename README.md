# lahar-map

Mapa de peligros del Volcán Villarrica sobre mapas base (satélite/calles/topográfico), con puntos propios
editables (se guardan solo en tu navegador). Sitio: https://calbornozflores.github.io/lahar-map/

**Herramienta personal de screening, no cartografía oficial. No usar para decisiones de compra,
construcción ni evacuación.** Para cualquier decisión, pedir el Certificado de Informaciones Previas en la
Municipalidad de Pucón y consultar a SERNAGEOMIN/ONEMI.

## Créditos
- Zonas de peligro: derivadas de *Mapa de Peligros del Volcán Villarrica*, Moreno, H. (2000), SERNAGEOMIN,
  Documentos de Trabajo N°17 (1:75.000). Vectorización aproximada por color desde un escaneo, georreferenciada
  (±50 m); AI1/ALI1 y AI2/ALI2 no se distinguen.
- Cauces: © colaboradores de OpenStreetMap (ODbL), digitalización aproximada.
- Mapas base: Esri World Imagery, © OpenStreetMap, © OpenTopoMap.
